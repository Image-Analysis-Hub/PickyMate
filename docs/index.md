# PickyMate Documentation

PickyMate curates particles picked in cryo-electron tomograms. Its core loop:
import template-matching picks together with their foundation-model
embeddings, confirm a few particles and reject a few, and let PickyMate
re-rank everything else by similarity to your decisions — so you review the
best candidates first and clear the rest in bulk.

Two windows make up the app: the **tomogram window** (three orthogonal slice
views and the tools) and the **Particle List** (thumbnail gallery, where sets
are managed).
