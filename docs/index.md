# PickyMate documentation

PickyMate curates particles picked in cryo-electron tomograms by template
matching or any other detector. Every imported pick carries an embedding from
a pretrained model; you confirm a few particles and reject a few, and
PickyMate re-ranks everything else by similarity to your decisions, so you
review the best candidates first and clear the rest in bulk. The
[README](../README.md) gives the overview; the [tutorial](../tutorial/) walks
through a complete session on two EMPIAR-10988 tomograms.

Two windows make up the app: the **tomogram window** (three orthogonal slice
views and the tools) and the **Particle List** (thumbnail gallery, where sets
are managed and ranking is launched).

## Preparing the inputs

PickyMate needs, per tomogram, a pick list and the embeddings of those picks.
Both are produced once, before the interactive session. Embedding only the
picks instead of the whole tomogram takes about a minute per tomogram on a
GPU.

**1. Template matching.** Run any engine (GapStop, pytom-match-pick,
STOPGAP, PyTME, ...) with a deliberately permissive threshold: PickyMate is
made for long candidate lists, and a particle absent from the list can never
be recovered. Save the candidates, best score first, as a plain text file of
`x y z` voxel coordinates, one pick per line. For the ribosomes of
EMPIAR-10988 the paper kept every peak above the 99.5th percentile of the
GapStop score map, about four candidates per true particle.

**2. TomoTwin embeddings.** TomoTwin embeds whole tomograms on a grid;
`tools/tomotwin_embed_picks.py` embeds only the picks, in the order of the
picks file, with a stock TomoTwin installation:

```
conda activate tomotwin
python tools/tomotwin_embed_picks.py -m tomotwin_latest.pth \
    -v TS_026.rec -c picks/TS_026.txt -o tomotwin/
tomotwin_tools.py umap -i tomotwin/TS_026.temb -o tomotwin/
```

The `.temb` is the embedding file and the `.tumap` from `tomotwin_tools.py
umap` its 2D projection; pass them with `--tomotwin_embeddings` and
`--tomotwin_umap`.

**3. CryoSiam embeddings** (optional second model). Denoise the tomogram with
CryoSiam's pretrained model, then embed the picks with
`tools/cryosiam_embed_picks.py`, which batches them so that tens of
thousands of picks fit in memory:

```
conda activate cryosiam
python tools/cryosiam_embed_picks.py -m simsiam_embeds_denoised_no_masking.ckpt \
    -v denoised/TS_026.rec -c picks/TS_026.txt -o cryosiam/
```

Pass the `_embeds.h5` with `--cryosiam_embeddings` and, for the 2D view, the
UMAP CSV written by CryoSiam's visualization tool with `--cryosiam_umap`.
Both models can be loaded at once and switched during a session. Each
script's docstring has the details.

Screenshots throughout show real data (EMPIAR-10988, ribosomes) and are
regenerated by `docs/make_figures.py`, so they stay true to the app.
